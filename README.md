## 이번 변경

- 배경 없는 투명 SEMIQOLON 로고, 어둡고 밝은 화면에 동일한 글자 사용
- 긴 글도 스크롤 없이 상단 중앙에서 녹음 시작·종료. 시작 후 버튼은 옅어지고 글 처음으로 이동
- 카카오톡 안에서는 Safari/Chrome 안내·링크 복사. 문장 인식 준비 상태를 글 위에서 확인
- 뒤로/앞으로 복귀 시 준비한 인식 엔진 유지. 첫 응답이 4.5초를 넘었다고 바로 실시간 표시를 끄던 기준을 12초로 완화
- 물결은 항상 화면 안에서 발생. 어두운 물 위에서도 반사광이 보이며 그래픽 대체 경로 부하 절감

- PC 서버 없이도 한국어 문장 인식: 기기에서 실행하는 Whisper base, 서버 인식 API 과금 없음
- 첫 사용 시 **문장 인식 준비**로 약 110MB 다운로드. 준비 중에도 녹음·저장 가능
- Android·Galaxy에서 사용할 공통 WebAssembly 방식, 별도 Worker에서 인식해 화면·녹음과 분리
- 기기 속도가 느리면 실시간 표시를 쉬고 녹음 후 전체 문장 확인. 실패해도 녹음 보존
- 읽은 문장 일치도, 단어별 시각에 맞춘 재생 표시, 말의 빠르기
- 원음 녹음 유지: 에코 제거·잡음 제거·자동 음량 조절을 끄도록 요청, WAV 보관
- “기록 마치기”에서만 빛으로 완성, 다른 탭에서는 어두운 시작 화면으로 복귀

## 이용 가능한 범위

녹음·재생·WAV 내려받기·기기 저장·높이·저중고음 비율·입력 크기(dBFS)·일별 기록·직접 원고/사진 글자 추출을 제공합니다. 목소리 높이와 음정 연습은 기기 안에서 처리합니다. 문장 일치도는 **인식된 글과 원고의 비교**이며 발음 정확도 점수가 아닙니다.

F1/F2 정밀 분석은 서버 미연결 상태입니다. Google·Apple 계정 로그인·기기 간 동기화도 연결 전입니다. 최초 측정 결과 저장은 이 브라우저의 프로필입니다. 클라우드 배포나 유료 API 연결은 이번 테스트에 포함하지 않았습니다.

## 저장·개인정보

기본 기능에서 음성은 업로드하지 않습니다. 인식 모델 파일만 Hugging Face에서 내려받아 브라우저 캐시에 둡니다. 캐시는 저장 공간 부족·브라우저 정책으로 지워질 수 있습니다. 녹음·원고·프로필은 같은 기기·브라우저에만 있습니다. 필요한 음성은 WAV로 내려받아 주세요. 사진은 기기에서 글자를 추출하며 업로드하지 않습니다.

## 검증 범위

Mac의 실제 브라우저에서 합성 한국어 음성으로 기기 내 변환과 단어 시각을 확인했습니다. 약 9.7초 입력의 기본 처리 변환은 약 5.2초였으며 한 조사가 다르게 인식되었습니다. 이 수치는 휴대폰 벤치마크가 아닙니다. 실제 iPhone·KakaoTalk·Galaxy·Android의 기종별 인식률, 배터리·발열·긴 녹음 성능은 테스트가 필요합니다. 모든 기기에서 즉시 인식된다고 보장하지 않습니다.
