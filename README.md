# SEMIQOLON · 한 문장 BETA

테스트 링크: https://noah-tv.github.io/semiqolon-beta/

2026-10-01 최신 작업본은 `app/`입니다. 기존 주소에서 자동으로 최신 앱을 엽니다.

위로·용기·감사·정보 → 녹음 → 목소리 분석 → 목표 설정 → 다시 읽기 → 전후 비교·일별 기록.

## 테스트 가능한 기능

- 녹음·재생·WAV 내려받기, 브라우저에 기록 저장
- 목소리 높이·저중고음 비율·마이크 입력 크기(dBFS) 분석
- 목소리 목표와 프로필, 전후 비교, 일별 기록 그래프

문장 인식·말의 빠르기·F1/F2는 외부 분석 서버 연결 전까지 준비 중입니다. 서버 주소와 코드는 넣지 않았고, 만료된 임시 서버로 녹음을 보내지 않습니다. Google·Apple 로그인과 클라우드 기록 동기화도 아직 연결 전입니다.

녹음은 사용한 기기·브라우저에 저장됩니다. 브라우저 데이터를 삭제하면 기록이 사라질 수 있으므로 필요한 녹음은 WAV로 내려받아 보관하세요. 마이크 입력값은 보정된 소음계 dB SPL이 아닙니다.

## 이전 기록

이전 버전은 `previous.html`에서 열 수 있습니다. 최신 앱 설정의 **이전 베타 기록 보기**로 이동하면 같은 브라우저에 남아 있는 예전 기록을 확인할 수 있습니다. 기존 저장소를 지우거나 자동 변환하지 않습니다.

## 변경 범위

GitHub Pages의 테스트 화면만 갱신합니다. Firebase·Cloud Run에는 배포하지 않았고 유료 서버도 생성하지 않았습니다. 자산 출처와 라이선스는 `licenses/`를 참고하세요.
