# SEMIQOLON · 한 문장 BETA

https://noah-tv.github.io/semiqolon-beta/

모바일 소규모 테스트용 프론트엔드입니다. iPhone Safari 또는 Android Chrome에서 직접 열어주세요.

문장 읽기 → 첫 녹음 → 분석·코칭 → 목표 음정 연습 → 선택 카메라 연습 → 다시 녹음 → 전후 비교.

녹음은 브라우저에 저장됩니다. 분석 시 녹음과 짧은 연습 음성을 HTTPS(Cloudflare)를 통해 운영자의 Mac으로 전송하며 분석 서버에는 파일을 저장하지 않습니다. 카메라 영상은 기기 안에서만 처리하고 저장하지 않습니다. 분석은 운영자가 알려준 테스트 코드로 연결하며, Mac과 임시 연결이 켜져 있어야 합니다. 코드나 녹음 파일은 이 저장소에 포함하지 않습니다.

음성 결과는 연습용 참고 정보이며, 건강 상태나 인체 부위를 진단하지 않습니다. 실제 모바일 기기에서의 정확도는 테스트 중입니다.
